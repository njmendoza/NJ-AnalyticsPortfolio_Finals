# Nathasha Jayne Mendoza Portfolio

This portfolio contains the midterm and final task pages for the course requirements.

## Final Task 1

### Step by Step

1. Create and prepare the call center table.
   Load the call center dataset into the database and confirm that the needed fields are available.

2. Preview and count the records.
   Show the first 10 rows, then count all rows to verify the total number of calls.

3. Group the calls by important categories.
   Summarize the records by sentiment, city, state, channel, and call center.

4. Analyze duration and response time.
   Calculate the minimum, maximum, and average call duration, then compare response time by call center.

## Final Task 2

### Step by Step

1. Import the flight tables.
   Load the airlines, airports, cancellation, and flights fact tables into Power BI.

2. Review the fields.
   Check fields such as airline code, airport code, cancellation code, delays, origin airport, and destination airport.

3. Build the data relationships.
   Connect the dimension tables to the flights fact table using the correct keys.

4. Validate the model.
   Inspect the model view and confirm that the relationships support proper filtering.

## Final Task 3

### Step by Step

1. Load the sales dataset.
   Open the Power BI sales file and check the available tables.

2. Create the needed measures.
   Build measures for sales, sales YTD, year-over-year growth, average price, median price, minimum price, maximum price, orders, and order lines.

3. Build the matrix report.
   Add fiscal year and month rows, then place the measures in the values area.

4. Format and review the results.
   Format currency, percentages, and totals so the report is ready for analysis.

## Final Task 4

### Step by Step

1. Prepare the sales and target model.
   Confirm that the Sales, Targets, Date, Region, Product, Reseller, and Salesperson tables are connected correctly.

2. Create dashboard measures.
   Set up measures for sales, target, variance, variance margin, profit, profit margin, orders, and cost.

3. Build the visual report page.
   Add card visuals, slicers, tables, and bar charts to compare sales and targets.

4. Test the dashboard filters.
   Use year and region filters to confirm that the visuals update properly.
